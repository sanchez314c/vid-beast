VidBeast — Comprehensive User Guide

Quick Start Guide

  1. Select Your Videos:
    • Click "Select Videos" to choose individual files or a folder
    • Enable "Recursive" to scan all subfolders
  2. Configure Analysis Options:
    • Enable Repair Mode: Automatically attempt repairs on corrupted files
    • Detailed Analysis: Perform deeper inspection (slower but more thorough)
    • Extract Frames: Save video frames as PNG images during analysis
  3. Set Output Location:
    • Click "Browse" next to Output Folder to choose where repaired files will be saved
    • VidBeast creates organized subfolders: /healthy/, /repaired/, /extracted_frames/
    • Original files are NEVER modified
  4. Start Analysis:
    • Click "Start Analysis" and watch real-time progress

Corruption Detection Levels

  • None (Healthy): File plays perfectly with no errors
  • Minor: Small metadata issues or index problems — usually fast to fix
  • Moderate: Missing keyframes or damaged headers — often repairable
  • Severe: Significant stream damage — repair possible but may lose content
  • Catastrophic: File structure severely damaged — frame extraction may be the only option

Repair Strategies

  • Extract Playable: Extracts video up to the first major error. Fast, preserves quality.
  • Container Repair: Rebuilds MP4/MOV container structure. Best for header/index issues.
  • Stream Remux: Extracts and repackages streams. Fixes timing and container corruption.
  • Deep Repair: Full re-encode with error-resilient settings. Slowest but most thorough.

Advanced Features

Frame Extraction:

  • Extract frames during analysis to preview video content
  • Choose frame rate: 0.1 fps (every 10s) to 30 fps (all frames)
  • Enable "Extract frames if all repairs fail" as a last resort

Output Formats:

  • MP4 (H.264): Most compatible, good quality/size balance
  • MP4 (HEVC/H.265): Better compression, requires newer devices
  • Apple MOV (ProRes): Professional quality, large files

Hardware Acceleration:

  • VideoToolbox (macOS), NVENC (NVIDIA), QuickSync (Intel), AMF (AMD)
  • Enable in Settings when available — falls back to CPU if GPU encoding fails

Troubleshooting

Analysis seems stuck:

  • Large files (>4GB) take longer — increase timeout in Settings
  • Try disabling Detailed Analysis mode

Repairs failing frequently:

  • Ensure output folder has enough free space
  • Check file permissions on output directory

FFmpeg not found:

  • Check Settings tab for FFmpeg status
  • Restart the app if detection fails
